Listening ratings

Eight 15-second clips (8 bars at 128 BPM). Listen to each and rate it 1–5 on three questions; add notes if you like. Clips are blind and in a different random order for each listener. Everything saves automatically in this browser; use Save to file to keep the results in the project and to resume elsewhere.

In Chrome or Edge, Save into project writes straight to output/listening/ratings.json (pick that file once per session; the page asks again after a reload). In other browsers, use Save to file and move the downloaded file there, so the notebook can read it. Loading a file merges it with what is here (the most recent edit of each rating wins), so listeners on different computers can each save a file and load them one after another.
